How this works

88 candidates, all built to the same constraints the library is: one burner, one pot, one pan, solo portion, ~3,000 kcal/day, spice 1–2, simple over clever. Burgers, pizza and pasta each get real weight because you named them. A “no” is worth as much as a “yes” — this repo has no dislikes list, and your rejections are how it gets one. Anything already in the kitchen is marked in the library; voting no on one of those is a real answer too.

Keyboard: Y / N / M votes the first unvoted dish and moves on. Votes save in this browser as you go.
