Why this page exists

Every geocoding host is blocked inside a Claude Code session — Nominatim, Overpass, Recreation.gov, the RIDB API. Not rate-limited: unreachable. So Claude cannot look up a coordinate, at all, ever, and no amount of asking changes that. Your browser can. This page is the half of the job that has to happen here, built so it takes seconds per waypoint instead of a hand-edit, and so nothing lands in a data file without a source attached to it.
